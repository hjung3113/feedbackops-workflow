# Triage labels

Matt Pocock workflow skills use five canonical roles. Use the same strings as GitHub labels in this repository.

| Skill role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for missing information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for agent execution |
| `ready-for-human` | `ready-for-human` | Requires a human decision or implementation |
| `wontfix` | `wontfix` | Intentionally not planned |

Creating or applying labels is an external write and still requires user authorization.
